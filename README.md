# HiFiCalc

Калькулятор кроссоверов акустических систем в Microsoft Excel с макросами VBA.
Репозиторий пока приватный, проект находится в разработке.

Подготовленная версия: **0.9.5**. Номер взят из имени книги
`HiFiCalc_0.9.5.xlsm` и папки исходного релиза.

## Использование

Скачайте [HiFiCalc_0.9.5.xlsm](HiFiCalc_0.9.5.xlsm) и откройте книгу в
настольном Microsoft Excel с поддержкой макросов VBA. Для работы пользовательских
функций разрешите макросы для этой книги. Начните с листов «Памятка» и
«Принцип подключения», затем перейдите к расчётным листам.

Книга содержит расчёты фильтров, электроакустический расчёт, ведомость закупки
и справочные таблицы. Совместимость с конкретными версиями Excel и другими
табличными редакторами пока не подтверждена.

## Состав репозитория

```text
HiFiCalc/
├── HiFiCalc_0.9.5.xlsm
├── src/
│   └── vba/
│       ├── BOM.bas
│       ├── OptimalBobbin.bas
│       ├── OptimalPairE24.bas
│       └── SpectralResistorPower.bas
├── README.md
├── CHANGELOG.md
├── LICENSE
├── .gitignore
└── .gitattributes
```

Рабочая книга находится в корне. В `src/vba/` сохранены все четыре
экспортированных пользователем модуля: ведомость закупки, подбор каркаса катушки,
подбор пары номиналов E24 и расчёт мощности резисторов.

Книга и модули перенесены из подготовленного релиза без изменения содержимого.
Модули `.bas` сохраняют исходную кодировку Windows-1251; при редактировании
используйте эту кодировку. Файл `.gitattributes` предотвращает автоматическое
изменение переводов строк в модулях и задаёт двоичный формат для книги.
Экспорты модулей не заменяют полную книгу: формулы, оформление, справочные данные
и встроенный проект VBA остаются внутри `.xlsm`.

При обновлении макросов сохраняйте книгу и повторно экспортируйте изменённые
модули в `src/vba/`. Описание изменений ведётся в [CHANGELOG.md](CHANGELOG.md).
Расчётные заметки пока остаются в книге; отдельная документация ещё не выделена.
